Side note: custom position

Override tip vertical position with extra CSS class and custom rule:

              css += ""\"
    .has_tip.tip_at_line_17 > blockquote:nth-child(1) {
      bottom: auto;
      top: 17em;
    }
""\"

Then use: classes = "has_tip tip_at_line_17"
